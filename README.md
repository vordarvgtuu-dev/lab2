# Домашнее задание к работе 2

## Условие задачи
Реактивный аэробус летит с пассажирами на борту из Лондона в Нью-Йорк. Три четверти пассажиров имеют билеты второго класса стоимостью х фунтов каждый. Остальные пассажиры имеют билеты первого класса, которые стоят вдвое дороже билетов второго класса. Напишите программу, которая выведет сумму денег, получаемую авиакомпанией от продажи билетов на этот рейс
### 1. Алгоритм и блок-схема
1. **Начало**
2. **Настроить вывод консоли на русский язык:**
- `SetConsoleOutputCP(65001)` установить кодировку UTF-8 для корректного отображения русского текста.
3. **Задать исходные данные:**
   - `x` — цена билета эконом-класса (фунты).
   - `N` — общее количество пассажиров на борту.
4. **Вычислить количество пассажиров второго класса:**
`secondClass_passengers` = `N` * 0.75 (три четверти — второй класс).
5. **Вычислить количество пассажиров первого класса:**
`firstClass_passengers` = `N` * 0.25 (остальные — первый класс).
6. **Вычислить цену билета первого класса:**
`firstClass_price` = 2 * x (вдвое дороже второго класса)
7. **Вычислить выручку по классам:**
   - `secondClass_revenue` = `secondClass_passengers` * `x`
   - `firstClass_revenue` = `firstClass_passengers` * `firstClass_price`
8. **Вычислить общую сумму:**
`total_sum` =` secondClass_revenue` + `firstClass_revenue`
9. **Вывести результаты расчетов** с подстановкой всех значений в текст (цена билетов, количество пассажиров, выручка по классам, общая сумма).
10. **Конец**

## 2. Реализация программы

#include <stdio.h>
#include <windows.h> // не работает #include <locale.h>

int main() {
    SetConsoleOutputCP(65001);
    float x = 100.;
    int N = 200;
    float secondClass_passengers = N * 0.75;
    float firstClass_passengers = N * 0.25;
    float firstClass_price = 2 * x;
    float secondClass_revenue = secondClass_passengers * x;
    float firstClass_revenue = firstClass_passengers * firstClass_price;
    float total_sum = secondClass_revenue + firstClass_revenue;
    printf(" Цена билета эконом. класса: %.2f фунтов\n Цена билета первого класса: %.2f фунтов\n Пассажиров эконом. класса: %.0f\n Пассажиров первого класса: %.0f\n\n Выручка билетов с эконом. класса: %.2f фунтов\n Выручка с билетов первого класса: %.2f фунтов\n\n Общая сумма: %.2f фунтов\n ", x, firstClass_price, secondClass_passengers, firstClass_passengers, secondClass_revenue, firstClass_revenue, total_sum);
    return 0;
}
